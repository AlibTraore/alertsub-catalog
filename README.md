# 📦 AlertSub - Catalogue Dynamique des Abonnements

Ce dépôt sert de source de vérité en temps réel pour l'application mobile **AlertSub**.

## 🚀 Fonctionnement
- Les tarifs, devises et métadonnées des abonnements sont centralisés dans [`catalog.json`](./catalog.json).
- L'application mobile consulte ce fichier au démarrage ou en arrière-plan.
- Les mises à jour de tarifs sont effectuées automatiquement sans nécessiter de nouvelle version sur les stores.

## 🔗 Liens d'accès
- **URL Directe Raw** : `https://raw.githubusercontent.com/AlibTraore/alertsub-catalog/main/catalog.json`
- **CDN Edge Global (jsDelivr)** : `https://cdn.jsdelivr.net/gh/AlibTraore/alertsub-catalog@main/catalog.json`
